# AngularJS: Introduction & Modules

Welcome to AngularJS! This note covers the fundamentals of AngularJS, its core concepts, directives, and how modules structure an application.

---

## 1. Introduction to AngularJS

### What is AngularJS?
AngularJS is a **structural framework** for dynamic web apps. It is an open-source JavaScript library developed by Google (specifically for AngularJS 1.x) that runs on the client side (in the browser). It extends standard HTML with new attributes, making web pages much more interactive and dynamic.

### The Problem It Solves: Single Page Applications (SPAs)
Before frameworks like AngularJS, every time a user clicked a button or navigated to a new page, the browser had to reload the *entire* HTML document from the server. This was slow and caused a jarring user experience.

AngularJS helps build **Single Page Applications (SPAs)**. In an SPA, the browser loads a single HTML page once. As the user interacts with the app, AngularJS dynamically updates parts of the page without reloading it, making it feel like a fast, native desktop or mobile application.

### Key Features
*   **Model-View-Controller (MVC) Architecture:** Separates the data (Model), user interface (View), and business logic (Controller).
*   **Extends HTML:** Introduces custom attributes called **directives** to add dynamic behavior to standard HTML.
*   **Two-Way Data Binding:** Automatically synchronizes data between the JavaScript code and the HTML view.
*   **Dependency Injection:** A design pattern that makes components easy to reuse, test, and maintain.

## 2. Core Directives: `ng-app`, `ng-init`, and `ng-model`

Directives are special markers on HTML tags (prefixed with `ng-`) that tell AngularJS to attach a specified behavior to that DOM element.

### A. `ng-app` (The Bootstrapper)
*   **What it does:** Defines the root element of an AngularJS application. It tells AngularJS, *"Hey, look here! This is the boundary of our app."*
*   **Where to put it:** Usually placed on the `<html>` or `<body>` tag. Without `ng-app`, AngularJS will ignore the page.

```html
<html ng-app>
  <!-- AngularJS is active inside this entire HTML tag -->
</html>
```

### B. `ng-init` (The Initializer)
*   **What it does:** Defines initial values/variables for your application.
*   **Use Case:** Useful for quick prototyping or setting default values, though in real apps, we prefer setting variables in Controllers.

```html
<div ng-app="" ng-init="price=10; quantity=5">
  <!-- We initialized two variables: price and quantity -->
</div>
```

### C. `ng-model` (The Binder)
*   **What it does:** Binds the value of HTML input controls (like text fields, checkboxes, dropdowns) to application data variables.
*   **How it works:** If you type into the input field, the variable updates. If the variable changes in JavaScript, the input field updates.

```html
<div ng-app="">
  <label>Enter Name:</label>
  <input type="text" ng-model="userName">
  <p>Hello, {{ userName }}!</p>
</div>
```

## 3. AngularJS Modules

### What is a Module?
Think of a **Module** as a container or a box for the different parts of your application: controllers, services, filters, directives, etc. It helps keep your code clean, modular, and organized.

### Creating a Module
We create a module using the `angular.module()` function.

```javascript
// Syntax: angular.module(name, [dependencies])
var myApp = angular.module("myAppModule", []);
```
*   `"myAppModule"`: The name of our application module.
*   `[]` (Empty Array): This is where we list other modules that this module depends on. Even if there are no dependencies, you **must** pass an empty array to create a new module.

### Retrieving an Existing Module
If you want to use/reference an already created module elsewhere in your code, call the function **without** the second argument (no array).

```javascript
// Retrieves the existing module
var myApp = angular.module("myAppModule");
```

### Hooking the Module to HTML
Once defined in JavaScript, you must link it to your HTML page by passing the module's name to the `ng-app` directive.

```html
<!DOCTYPE html>
<html>
<head>
  <!-- Load AngularJS Library -->
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
</head>
<body ng-app="myAppModule">

  <h1>Welcome to my AngularJS App</h1>

  <script>
    // Create the module in JavaScript
    angular.module("myAppModule", []);
  </script>
</body>
</html>
```
