# AngularJS: DOM & Events

This note explains how AngularJS interacts with the HTML Document Object Model (DOM) using built-in directives and handles user events like clicks, keypresses, and change events.

---

## 1. DOM Directives

AngularJS provides directives to dynamically manipulate DOM elements based on application state.

### A. `ng-disabled`
Binds the HTML `disabled` attribute of elements (like buttons, inputs) to an AngularJS expression. If the expression evaluates to `true`, the element is disabled.

```html
<div ng-app="" ng-init="isAgreed=false">
  <label>
    <input type="checkbox" ng-model="isAgreed"> I agree to the terms
  </label>
  <br>
  <!-- Button is disabled if checkbox is NOT checked -->
  <button ng-disabled="!isAgreed">Submit Register</button>
</div>
```

### B. `ng-show` and `ng-hide`
*   **`ng-show`:** Shows an HTML element if the expression is `true`. If `false`, it hides the element by applying `display: none !important;` CSS rules.
*   **`ng-hide`:** Hides an HTML element if the expression is `true`. If `false`, it shows the element.

```html
<div ng-app="" ng-init="isMember=false">
  <label>
    <input type="checkbox" ng-model="isMember"> I am a premium member
  </label>

  <p ng-show="isMember">Welcome Premium User! Enjoy your ad-free experience.</p>
  <p ng-hide="isMember">Please sign up for premium to remove ads.</p>
</div>
```

### C. `ng-style` and `ng-class`
*   **`ng-style`:** Dynamically sets CSS styles.
*   **`ng-class`:** Dynamically sets CSS classes based on expressions.

```html
<!-- ng-style example -->
<div ng-style="{ 'color': myColor, 'background-color': 'lightgray' }">
  Dynamic style text
</div>

<!-- ng-class example (applies 'error' class if isError is true) -->
<div ng-class="{ 'error-border': isError, 'success-border': !isError }">
  Status Message
</div>
```

## 2. Event Handling in AngularJS

AngularJS allows you to handle user actions (mouse clicks, keyboard input, form changes) directly within the HTML using special event directives.

### List of Common Event Directives

| Directive | Trigger Event |
| :--- | :--- |
| `ng-click` | Element is clicked |
| `ng-dblclick` | Element is double-clicked |
| `ng-mouseenter` | Mouse enters the element boundary |
| `ng-mouseleave` | Mouse leaves the element boundary |
| `ng-keydown` | Key is pressed down |
| `ng-change` | Value of an input element changes (must be used with `ng-model`) |

### Example: Click Counter and Dropdown Change

**JavaScript (`controller.js`):**
```javascript
var app = angular.module("eventApp", []);

app.controller("EventController", function($scope) {
    $scope.count = 0;
    $scope.selectedCar = "";

    // Increment count on click
    $scope.incrementCount = function() {
        $scope.count++;
    };

    // Respond to selection change
    $scope.carChanged = function() {
        console.log("Selected car changed to: " + $scope.selectedCar);
    };
});
```

**HTML:**
```html
<div ng-app="eventApp" ng-controller="EventController">
  <!-- Click event -->
  <button ng-click="incrementCount()">Click me!</button>
  <p>You have clicked the button {{ count }} times.</p>

  <hr>

  <!-- Change event (requires ng-model) -->
  <label>Select a car:</label>
  <select ng-model="selectedCar" ng-change="carChanged()">
    <option value="Tesla">Tesla</option>
    <option value="BMW">BMW</option>
    <option value="Audi">Audi</option>
  </select>
  <p>Current Selection: {{ selectedCar }}</p>
</div>
```

## 3. Passing Event Object: `$event`
Sometimes you need to access the browser's native event object (e.g., to find coordinate positions, prevent default action, or check which key was pressed). AngularJS provides a special variable named `$event` which can be passed to the controller function.

```html
<div ng-app="eventApp" ng-controller="CoordsController">
  <!-- Pass the special $event object -->
  <div ng-mousemove="showCoords($event)" style="width:200px; height:200px; border:1px solid black;">
    Move mouse here
  </div>
  <p>Coordinates: X: {{ x }}, Y: {{ y }}</p>
</div>
```

```javascript
app.controller("CoordsController", function($scope) {
    $scope.x = 0;
    $scope.y = 0;
    
    $scope.showCoords = function(event) {
        $scope.x = event.clientX;
        $scope.y = event.clientY;
    };
});
```
