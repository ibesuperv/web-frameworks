# AngularJS: Forms & Validations

Forms and validations are core parts of modern web apps. AngularJS provides rich support for form controls, validation directives, and CSS classes that reflect the state of forms.

---

## 1. Form and Input State Properties

AngularJS automatically tracks the state of forms and inputs. To use state tracking, both the `<form>` and the `<input>` elements must have a `name` attribute.

### State Variables Table
You can access these properties on your form or individual inputs using the pattern: `formName.inputName.property` or `formName.property`.

| Property | Description | True when... | False when... |
| :--- | :--- | :--- | :--- |
| **`$pristine`** | Pristine (unspoiled) state | The user has **not** interacted with the control yet. | The user has typed or edited the input. |
| **`$dirty`** | Dirty (modified) state | The user **has** modified the input/form. | No user changes have been made. |
| **`$valid`** | Validity state | All validations are passing. | At least one validation fails. |
| **`$invalid`** | Invalid state | At least one validation is failing. | All validations pass. |
| **`$touched`** | Touched state | The user has clicked inside and then blurred (focused away) from the input. | Input hasn't lost focus yet. |
| **`$untouched`**| Untouched state | The user has **not** lost focus from the input yet. | Input has lost focus at least once. |

---

## 2. CSS State Classes

AngularJS automatically appends and removes CSS classes to `<form>` and `<input>` elements as their state changes. This is extremely helpful for styling valid/invalid fields dynamically!

### Automatic CSS Classes Added:
*   `ng-pristine` / `ng-dirty`
*   `ng-valid` / `ng-invalid`
*   `ng-touched` / `ng-untouched`

### Styling Example (CSS)
```css
/* Style invalid inputs with a red border */
input.ng-invalid.ng-touched {
    border: 2px solid red;
    background-color: #fdd;
}

/* Style valid inputs with a green border */
input.ng-valid.ng-touched {
    border: 2px solid green;
    background-color: #dfd;
}
```

## 3. Complete Form Validation Example

Here is a practical, beginner-friendly example of a form with name, email, and validation messages.

### HTML:
```html
<!DOCTYPE html>
<html>
<head>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <style>
    .error-msg {
      color: red;
      font-size: 12px;
    }
    input.ng-invalid.ng-touched {
      border: 1px solid red;
    }
  </style>
</head>
<body ng-app="formApp">

  <!-- novalidate disables standard HTML5 validation so AngularJS can handle it entirely -->
  <form name="signupForm" ng-submit="submitForm(signupForm.$valid)" novalidate>
    
    <!-- Username Field -->
    <div>
      <label>Username (Required, min 4 chars):</label>
      <input type="text" name="username" ng-model="user.username" required ng-minlength="4">
      
      <!-- Error messages show up ONLY if the input is dirty or touched -->
      <div class="error-msg" ng-show="signupForm.username.$touched && signupForm.username.$invalid">
        <span ng-show="signupForm.username.$error.required">Username is required.</span>
        <span ng-show="signupForm.username.$error.minlength">Username must be at least 4 characters long.</span>
      </div>
    </div>

    <!-- Email Field -->
    <div style="margin-top:10px;">
      <label>Email (Required, valid format):</label>
      <input type="email" name="email" ng-model="user.email" required>
      
      <div class="error-msg" ng-show="signupForm.email.$touched && signupForm.email.$invalid">
        <span ng-show="signupForm.email.$error.required">Email is required.</span>
        <span ng-show="signupForm.email.$error.email">Invalid email format.</span>
      </div>
    </div>

    <!-- Submit Button -->
    <div style="margin-top:15px;">
      <!-- Disable the button entirely if the overall form is invalid -->
      <button type="submit" ng-disabled="signupForm.$invalid">Register</button>
    </div>

  </form>

  <script>
    var app = angular.module("formApp", []);
    app.controller("FormController", function($scope) {
        $scope.user = {};
        
        $scope.submitForm = function(isValid) {
            if (isValid) {
                alert("Form is valid! Submitting details...");
            } else {
                alert("Form is invalid. Please correct errors.");
            }
        };
    });
  </script>
</body>
</html>
```
