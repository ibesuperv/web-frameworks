# AngularJS: Controllers & Scope

This note explains how to manage application behavior using Controllers and how the `$scope` object acts as the bridge between the View and the Controller.

---

## 1. AngularJS Controllers

### What is a Controller?
In AngularJS, a **Controller** is a JavaScript constructor function that is used to control the flow of data in the application. It contains the business logic, state, and functions for a specific part of the screen.

### Purpose of a Controller
*   Setting up the initial state of the `$scope` object.
*   Adding behavior (functions) to the `$scope` object.
*   Responding to user interactions (e.g., button clicks, form submissions).

### How to Register and Use a Controller
1.  **Define in JavaScript:** Register it on your module using the `.controller()` method.
2.  **Attach to HTML:** Use the `ng-controller` directive to attach the controller to a specific DOM element.

#### Example:
**JavaScript (`app.js`):**
```javascript
// 1. Get reference to our module
var app = angular.module("myApp", []);

// 2. Define the controller
app.controller("StudentController", function($scope) {
    // Setting initial state
    $scope.firstName = "Rahul";
    $scope.lastName = "Sharma";

    // Adding behavior (a function)
    $scope.fullName = function() {
        return $scope.firstName + " " + $scope.lastName;
    };
});
```

**HTML:**
```html
<div ng-app="myApp" ng-controller="StudentController">
  <p>First Name: <input type="text" ng-model="firstName"></p>
  <p>Last Name: <input type="text" ng-model="lastName"></p>
  
  <h3>Student Details:</h3>
  <!-- Evaluating controller variables and functions -->
  <p>Full Name: {{ fullName() }}</p>
</div>
```

## 2. Understanding the `$scope` Object

### What is `$scope`?
The `$scope` is a special built-in object that acts as a glue or bridge between the **Controller** and the **View** (HTML). 
*   **Controller perspective:** Properties and functions are added to `$scope` to expose them to the View.
*   **View perspective:** The View can access only those properties and functions that are attached to `$scope`.

```
  +------------------+                    +-----------------+
  |    Controller    |  <-- $scope -->   |      View       |
  | (JS code logic)  |                    |  (HTML markup)  |
  +------------------+                    +-----------------+
```

### Scope Inheritance
AngularJS scopes are organized hierarchically, matching the structure of the DOM elements they are attached to.
*   **`$rootScope`:** The top-level scope created on the element with `ng-app`. Every application has exactly one `$rootScope`. All other scopes are child scopes of `$rootScope`.
*   **Scope Chain:** If a controller tries to read a property that is not defined on its own `$scope`, it looks up the parent scope hierarchy, all the way up to `$rootScope`.

#### Example of Scope Inheritance:
```html
<div ng-app="myApp" ng-init="schoolName='High School'">
  <!-- Parent Scope (has schoolName) -->

  <div ng-controller="ParentController">
    <!-- Child Scope 1 -->
    <p>School: {{ schoolName }}</p> <!-- Inherited from parent -->
    <p>Parent Name: {{ parentName }}</p>

    <div ng-controller="ChildController">
      <!-- Child Scope 2 -->
      <p>School: {{ schoolName }}</p> <!-- Inherited from grandparent -->
      <p>Parent Name: {{ parentName }}</p> <!-- Inherited from parent -->
      <p>Child Name: {{ childName }}</p>
    </div>
  </div>
</div>
```

**JavaScript:**
```javascript
var app = angular.module("myApp", []);

app.controller("ParentController", function($scope) {
    $scope.parentName = "Amit Kumar";
});

app.controller("ChildController", function($scope) {
    $scope.childName = "Aarav Kumar";
});
```

### Important Rule for Beginners: "The Dot Rule"
When using `ng-model`, it is highly recommended to bind to a property of an object (e.g., `ng-model="user.name"`) rather than a primitive variable directly (e.g., `ng-model="name"`). 
Due to JavaScript's prototype inheritance rules, if a child scope writes to a primitive value from a parent scope, it creates a new local property instead of modifying the parent property. Using a dot (`.`) ensures you are modifying the object defined in the parent scope.
