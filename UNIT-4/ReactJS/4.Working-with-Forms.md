# React.js: Working with Forms

In React, forms can be managed in two distinct ways: **Controlled Components** and **Uncontrolled Components**. This note covers both models, how to manage multiple inputs, and how to handle form submissions.

---

## 1. Controlled vs. Uncontrolled Components

| Feature | Controlled Components (Recommended) | Uncontrolled Components |
| :--- | :--- | :--- |
| **Source of Truth** | React State | Real DOM (retrieved via `ref`) |
| **Data Flow** | Synchronous two-way flow via state and `onChange` | Read directly from DOM when needed |
| **Validation** | Easy to validate on every keystroke | Validated only when form is submitted |
| **Best Used For** | Normal forms, dynamic inputs, immediate feedback | Integrating third-party non-React libraries |

---

## 2. Controlled Components

In a controlled component, form input data is handled by a React component's **state**. The input's current value is bound to the state variable (`value={stateVar}`), and updates are handled by an event function (`onChange={handleUpdate}`).

```jsx
import React, { useState } from 'react';

function ControlledForm() {
  const [name, setName] = useState('');

  const handleSubmit = (event) => {
    event.preventDefault(); // Prevents page reload on form submit
    alert(`Submitted Name: ${name}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Enter Name:
        {/* Value is driven by React state; onChange updates the state */}
        <input 
          type="text" 
          value={name} 
          onChange={(e) => setName(e.target.value)} 
        />
      </label>
      <button type="submit">Submit</button>
    </form>
  );
}
```

---

## 3. Uncontrolled Components

In an uncontrolled component, form data is handled by the **DOM itself**. To get the values, you query the DOM using React **`refs`** instead of writing event handlers for every input.

```jsx
import React, { useRef } from 'react';

function UncontrolledForm() {
  // Create a ref to attach to the input element
  const inputRef = useRef(null);

  const handleSubmit = (event) => {
    event.preventDefault();
    // Access input value directly from the DOM reference
    alert(`Submitted Name: ${inputRef.current.value}`);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Enter Name:
        {/* Attaching the ref here */}
        <input type="text" ref={inputRef} />
      </label>
      <button type="submit">Submit</button>
    </form>
  );
}
```

## 4. Handling Multiple Inputs in Controlled Forms

When building a form with many fields, writing separate state variables and handler functions for each input becomes tedious. Instead, you can use a single **state object** and a **single event handler** that uses the input's `name` attribute.

```jsx
import React, { useState } from 'react';

function MultiInputForm() {
  // 1. Single state object for all fields
  const [formData, setFormData] = useState({
      username: '',
      email: '',
      role: 'Student'
  });

  // 2. Single handler function
  const handleChange = (event) => {
      const { name, value } = event.target;
      
      // Update only the field that triggered the change using dynamic key names
      setFormData({
          ...formData, // Copy existing data
          [name]: value // Overwrite the specific changed field
      });
  };

  const handleSubmit = (event) => {
      event.preventDefault();
      console.log("Form Data Submitted:", formData);
  };

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Username:</label>
        <input 
          type="text" 
          name="username" 
          value={formData.username} 
          onChange={handleChange} 
        />
      </div>

      <div>
        <label>Email:</label>
        <input 
          type="email" 
          name="email" 
          value={formData.email} 
          onChange={handleChange} 
        />
      </div>

      <div>
        <label>Role:</label>
        <select name="role" value={formData.role} onChange={handleChange}>
          <option value="Student">Student</option>
          <option value="Teacher">Teacher</option>
          <option value="Admin">Admin</option>
        </select>
      </div>

      <button type="submit">Submit</button>
    </form>
  );
}
```
*Note the use of the ES6 spread operator (`...formData`) and dynamic object keys (`[name]: value`). This is a very common design pattern for forms in React.*
