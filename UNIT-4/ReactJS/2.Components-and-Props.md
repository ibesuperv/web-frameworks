# React.js: Components & Props

Components and Props are the building blocks of a React application. This note covers JSX syntax, the types of components, and how to pass data using props.

---

## 1. What is JSX?

**JSX** stands for **JavaScript XML**. It is a syntax extension for JavaScript that allows you to write HTML-like markup directly inside a JavaScript file.

### JSX Example:
```jsx
const element = <h1>Hello, World!</h1>;
```

### Key Rules of JSX:
1.  **Return a Single Root Element:** You must wrap multiple sibling elements in a single parent tag (like `<div>` or a React Fragment `<> </>`).
    ```jsx
    // Correct
    return (
      <>
        <h1>Heading</h1>
        <p>Paragraph</p>
      </>
    );
    ```
2.  **Close All Tags:** All HTML tags must be explicitly closed (e.g., `<br />`, `<img />`, `<input />`).
3.  **Use camelCase for HTML Attributes:** Since JSX is JavaScript, attribute names are camelCased. For example, `class` becomes `className`, and `onclick` becomes `onClick`.
4.  **JavaScript Expressions inside JSX:** You can evaluate JavaScript expressions inside JSX by wrapping them in single curly braces `{}`.
    ```jsx
    const name = "Varun";
    return <h1>Hello, {name}</h1>; // Renders: Hello, Varun
    ```

## 2. Understanding Components

Components are independent, reusable chunks of UI. There are two primary types of components in React:

### A. Functional Components
These are simple JavaScript functions that accept `props` as an argument and return a React element (JSX). They are the modern standard in React development.

```jsx
// Modern Functional Component
function WelcomeMessage() {
  return <h2>Welcome to React learning!</h2>;
}
```

### B. Class Components
These are ES6 classes that extend `React.Component` and must include a `render()` method that returns JSX. While older code bases use class components, modern React relies almost entirely on Functional Components with Hooks.

```jsx
import React, { Component } from 'react';

class WelcomeMessageClass extends Component {
  render() {
    return <h2>Welcome to React learning from a Class!</h2>;
  }
}
```

## 3. Props (Properties)

**Props** (short for properties) are read-only inputs passed to components. They allow you to pass data from a **Parent Component** down to a **Child Component**.

### The Golden Rule: Props are Read-Only (Immutable)
A component must **never** modify its own props. Props are owned by the parent component and should remain constant from the child's perspective. If you need to change data within a component, you must use **State** instead of Props.

### Example: Passing and Using Props

#### 1. Defining the Child Component:
```jsx
// ChildComponent.jsx
function UserCard(props) {
  return (
    <div className="user-card">
      <h3>Name: {props.name}</h3>
      <p>Role: {props.role}</p>
    </div>
  );
}
```

#### 2. Using it in the Parent Component:
```jsx
// ParentComponent.jsx
function App() {
  return (
    <div>
      <h1>Our Team Directory</h1>
      {/* Passing data down using custom attributes */}
      <UserCard name="Varun" role="Software Engineer" />
      <UserCard name="Aditi" role="UI Designer" />
    </div>
  );
}
```
*In this example, the `UserCard` child component displays different names and roles based on the attributes passed by its parent `App` component.*
