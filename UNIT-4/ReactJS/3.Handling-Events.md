# React.js: Handling Events

Handling user events (clicks, keypresses, hover events) in React is very similar to handling events on HTML DOM elements, but with a few key differences. This note covers event syntax, synthetic events, and passing arguments.

---

## 1. Event Handling Syntax: React vs. HTML

In React, event handling differs from traditional HTML in two primary ways:
1.  **Naming Convention:** React events are named using camelCase (e.g., `onClick`, `onSubmit`, `onChange`) rather than lowercase (`onclick`, `onsubmit`, `onchange`).
2.  **Passing Functions:** In JSX, you pass a reference to a **JavaScript function** inside curly braces, rather than a string of code.

### Syntax Comparison:

**Traditional HTML:**
```html
<button onclick="handleClick()">
  Click Me
</button>
```

**React JSX:**
```jsx
// Correct: Pass the function itself
<button onClick={handleClick}>
  Click Me
</button>
```
*Note: Do NOT add parentheses `onClick={handleClick()}` inside the event binder. If you do, the function will execute immediately during rendering, rather than waiting for the user to click.*

---

## 2. Synthetic Events

Under the hood, React does not bind events directly to real DOM elements. Instead, it wraps native browser events inside a cross-browser object called a **`SyntheticEvent`**.

### What is a SyntheticEvent?
It is a wrapper around the browser’s native event system. 

### Why does React do this?
*   **Cross-Browser Compatibility:** Different browsers handle event details slightly differently. React’s `SyntheticEvent` ensures that events behave exactly the same way across Chrome, Safari, Firefox, and Edge.
*   **Performance Optimization:** React uses event delegation (attaching a single event handler to the root element) to improve performance.

You can access properties (like `event.target` or `event.preventDefault()`) exactly like you would in normal JavaScript.

---

## 3. Practical Example: Click and Input Change

Here is a functional component demonstrating how to handle click events and input change events.

```jsx
import React, { useState } from 'react';

function InteractiveButton() {
  const [clickCount, setClickCount] = useState(0);

  // 1. Click Handler
  const handleButtonClick = () => {
      setClickCount(clickCount + 1);
  };

  // 2. Change Handler
  const handleInputChange = (event) => {
      // event.target refers to the input element
      console.log("Input value is: " + event.target.value);
  };

  return (
    <div>
      {/* Binding click handler */}
      <button onClick={handleButtonClick}>Clicks: {clickCount}</button>
      
      <br /><br />
      
      {/* Binding change handler and capturing the event object */}
      <input type="text" placeholder="Type here..." onChange={handleInputChange} />
    </div>
  );
}
```

## 4. Passing Arguments to Event Handlers

If you want to pass custom arguments (like an ID) to your event handler, wrap the handler in an arrow function.

### Example:
```jsx
function UserList() {
  const deleteUser = (userId) => {
      alert("Deleting user with ID: " + userId);
  };

  return (
    <ul>
      {/* Wrap function call in an arrow function wrapper */}
      <li>User A <button onClick={() => deleteUser(101)}>Delete</button></li>
      <li>User B <button onClick={() => deleteUser(102)}>Delete</button></li>
    </ul>
  );
}
```
*By writing `onClick={() => deleteUser(101)}`, we prevent the function from running instantly, while still passing the parameters we need.*
