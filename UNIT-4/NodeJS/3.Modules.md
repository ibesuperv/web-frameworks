# Node.js: Modules

In Node.js, code is modular. This note covers what modules are, how to use built-in core modules, and how to create and export your own custom modules.

---

## 1. What is a Module?

A **Module** is a block of reusable code whose details are encapsulated. It is like a separate JavaScript file that contains a set of functions or variables that you want to include in your main application. 

### Why Use Modules?
*   **Maintainability:** Keeps your files small, focused, and clean.
*   **Reusability:** Write once, use across multiple files.
*   **Namespacing:** Variables defined in one module do not pollute the global scope.

---

## 2. Core (Built-in) Modules

Node.js comes with a set of built-in modules that you can use without installing anything extra. To use them, import them with the `require()` function.

### A. The `path` Module
Used to handle and transform file paths.
```javascript
const path = require('path');

// Join folder paths cleanly (cross-platform compatible)
const fullPath = path.join('users', 'varun', 'documents', 'notes.txt');
console.log(fullPath); // Output: users/varun/documents/notes.txt (on macOS/Linux) or users\varun\documents\notes.txt (on Windows)

// Get file extension
console.log(path.extname('index.html')); // Output: .html
```

### B. The `fs` (File System) Module
Used to read, write, create, and delete files on your computer.
```javascript
const fs = require('fs');

// 1. Write to a file (creates it if it doesn't exist)
fs.writeFileSync('hello.txt', 'Hello, Node.js World!');

// 2. Read from a file
const content = fs.readFileSync('hello.txt', 'utf8');
console.log(content); // Output: Hello, Node.js World!
```

### C. The `http` Module
Used to create a web server that listens to ports and responds to client requests.
```javascript
const http = require('http');

// Create the server
const server = http.createServer((req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/plain' });
    res.end('Hello from my local Node.js Server!');
});

// Run server on port 3000
server.listen(3000, () => {
    console.log('Server is running on http://localhost:3000');
});
```

## 3. Creating Custom Modules (CommonJS Syntax)

In Node.js (by default, CommonJS syntax), every file is treated as a separate module. You can share variables or functions from one file to another using `module.exports` and `require`.

### Step 1: Create the Module (`math.js`)
We define functions and specify what should be visible to other files using `module.exports`.

```javascript
// math.js

const add = (a, b) => a + b;
const subtract = (a, b) => a - b;

// Export an object containing our functions
module.exports = {
    add,
    subtract
};
```

### Step 2: Consume the Module (`app.js`)
We use `require()` to import the exported features from `math.js`.

```javascript
// app.js

// Include local file using relative path './'
const mathObj = require('./math');

console.log("Addition: " + mathObj.add(10, 5));        // Output: Addition: 15
console.log("Subtraction: " + mathObj.subtract(10, 5));  // Output: Subtraction: 5
```
