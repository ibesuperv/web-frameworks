# Node.js: Introduction & Basics

Welcome to Node.js! This note covers what Node.js is, why it is so popular, how to install it, and basic scripting concepts.

---

## 1. What is Node.js?

Traditionally, JavaScript only lived inside the web browser. It was used to handle front-end interactive features (like dropdown menus, animations, and forms). If you wanted to build a backend (server, database connections, file system operations), you had to use languages like Java, PHP, Python, or Ruby.

**Node.js** changed everything. It is an open-source, cross-platform **runtime environment** that allows you to run JavaScript code outside of the browser, directly on your operating system (server-side).

### The Engine Under the Hood: Google V8
Node.js is built on **Google Chrome's V8 JavaScript engine**. V8 compiles JavaScript code directly into native machine code (the binary language that computers understand directly), making it incredibly fast.

---

## 2. Advantages of Node.js

*   **Single Programming Language:** Developers can use JavaScript for both the frontend (browser UI) and backend (server). This is called **Full-Stack JavaScript**.
*   **High Performance:** Powered by the Google V8 engine, code executes extremely fast.
*   **Asynchronous & Event-Driven:** Node.js uses non-blocking I/O operations (explained in detail in Note 2), making it perfect for data-intensive real-time applications.
*   **Massive Ecosystem (NPM):** Node Package Manager (NPM) hosts millions of free, open-source packages and libraries that you can install with a single command.
*   **Rich Library support:** Node.js has robust built-in libraries for working with files, network sockets, HTTP servers, and more.

---

## 3. Installation of Node.js

To set up Node.js on your computer:
1.  **Download:** Visit the official website [nodejs.org](https://nodejs.org) and download the **LTS (Long Term Support)** version for your operating system (Windows, macOS, or Linux).
2.  **Run Installer:** Follow the installation steps. It will automatically install:
    *   **Node.js Runtime** (executes your JavaScript code).
    *   **NPM** (Node Package Manager).
3.  **Verify Installation:** Open your terminal (Command Prompt, PowerShell, or Bash) and run:
    ```bash
    node -v
    npm -v
    ```
    *If successful, these commands will output the installed version numbers (e.g., `v18.16.0` and `9.5.1`).*

---

## 4. Node.js Basics

Once installed, there are two primary ways to run JavaScript using Node.js:

### A. The REPL (Read-Eval-Print Loop)
REPL is an interactive computer environment (like a playground) where you can type JavaScript code and see the results immediately.
*   To start it: Open your terminal, type `node`, and hit **Enter**.
*   To exit it: Type `.exit` or press `Ctrl + C` twice.

**Example session:**
```bash
$ node
> 2 + 2
4
> console.log("Hello from REPL");
Hello from REPL
undefined
> 
```

### B. Running Scripts via Files
In professional development, we write code in `.js` files and execute them.

1.  Create a file named `app.js` and add this code:
    ```javascript
    // app.js
    const username = "Varun";
    console.log(`Hello, ${username}! Welcome to Node.js.`);
    ```
2.  Run the file from your terminal:
    ```bash
    node app.js
    ```
3.  **Output:**
    ```bash
    Hello, Varun! Welcome to Node.js.
    ```
