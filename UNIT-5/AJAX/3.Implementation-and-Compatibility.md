# AJAX: Code Implementation & Compatibility

This note covers how to write raw AJAX code, handle cross-browser compatibility issues, and how it compares to modern APIs like `fetch`.

---

## 1. Raw JavaScript AJAX Implementation

Here is the standard JavaScript implementation using the native `XMLHttpRequest` object.

```javascript
// 1. Create XMLHttpRequest object
var xhr = new XMLHttpRequest();

// 2. Configure request (Method, URL, Async flag)
xhr.open("GET", "https://jsonplaceholder.typicode.com/users/1", true);

// 3. Define Callback function for State Changes
xhr.onreadystatechange = function() {
    // readyState 4 = Request is finished and response is ready
    // status 200 = HTTP Success status
    if (xhr.readyState === 4 && xhr.status === 200) {
        // Parse the text string into a JSON object
        var userData = JSON.parse(xhr.responseText);
        console.log("User Name:", userData.name);
        
        // Update DOM element
        document.getElementById("userNameDisplay").innerText = userData.name;
    }
};

// 4. Send the request
xhr.send();
```

---

## 2. Understanding Ready States (`readyState`)

The `readyState` property holds the status of the XMLHttpRequest object from start to finish.

| State Code | Constant Name | Description |
| :--- | :--- | :--- |
| **0** | `UNSENT` | Client has been created. `open()` has not been called yet. |
| **1** | `OPENED` | `open()` has been called. |
| **2** | `HEADERS_RECEIVED` | `send()` has been called, headers and status are available. |
| **3** | `LOADING` | Downloading response content; `responseText` holds partial data. |
| **4** | `DONE` | The operation is complete. Data is fully downloaded. |

## 3. Cross-Browser Support (Legacy IE compatibility)

Modern browsers (Chrome, Firefox, Safari, Edge, and IE 7+) have built-in support for the standard `XMLHttpRequest` object.
However, very old versions of Internet Explorer (IE 5 and IE 6) used Microsoft-specific ActiveX controls. 

To support all browsers, you write a fallback check function to instantiate the correct object:

```javascript
function createXHR() {
    var xhr = null;

    if (window.XMLHttpRequest) {
        // Modern browsers (IE7+, Chrome, Firefox, Safari, Opera)
        xhr = new XMLHttpRequest();
    } else if (window.ActiveXObject) {
        // Old Internet Explorer (IE5 and IE6)
        try {
            xhr = new ActiveXObject("Msxml2.XMLHTTP");
        } catch (e) {
            try {
                xhr = new ActiveXObject("Microsoft.XMLHTTP");
            } catch (e) {
                console.error("This browser does not support AJAX.");
            }
        }
    }
    return xhr;
}
```

## 4. Modern Alternative: The Fetch API

Writing raw `XMLHttpRequest` is verbose and uses complex callback patterns. Modern browsers support the **Fetch API**, which is built on ES6 **Promises**, making it much cleaner to write and read.

### AJAX (XHR) vs. Fetch:

**XHR Syntax:**
```javascript
var xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com", true);
xhr.onreadystatechange = function() {
    if (xhr.readyState === 4 && xhr.status === 200) {
        console.log(JSON.parse(xhr.responseText));
    }
};
xhr.send();
```

**Fetch Syntax:**
```javascript
fetch("https://api.example.com")
    .then(response => response.json()) // Automatically parses JSON
    .then(data => console.log(data))
    .catch(error => console.error("Error:", error));
```
*Note: While Fetch is standard in modern projects, understanding the raw `XMLHttpRequest` workflow is critical for university exam questions!*
