# Django: Introduction & Installation

Welcome to Django! This note covers what Django is, its relationship with Python, and a step-by-step setup guide.

---

## 1. What is Django?

**Django** is a free, open-source, **high-level Python web framework** designed to help developers build secure, maintainable, and scalable web applications quickly.

### The Philosophy: "Batteries Included"
Unlike lightweight micro-frameworks (such as Flask or Express.js) where you must choose and configure your own database management, login authentication, and admin tools, Django comes with all of these built-in. This is known as the **"batteries-included"** philosophy.

### Key Features of Django:
*   **Rapid Development:** Designed to take applications from concept to completion as quickly as possible.
*   **Secure:** Helps developers avoid common security mistakes (like SQL injection, cross-site scripting, and cross-site request forgery).
*   **Scalable:** Can handle heavy traffic demands (used by Instagram, Pinterest, and Disqus).
*   **Built-in Admin Panel:** Automatically generates a fully functioning administrative user interface for managing data models.

---

## 2. Django and Python

Django is written entirely in **Python**. 

### Why Python?
*   Python's clean, readable syntax makes Django code easy to read and maintain.
*   It allows web developers to easily integrate Python's massive library ecosystem (especially for machine learning, data analysis, and scripting).
*   Django relies on Python objects to map database tables. This means you can write database queries using Python code instead of writing raw SQL (this is called **Object-Relational Mapping (ORM)**).

---

## 3. Installation & Getting Started

Follow these step-by-step instructions to create a Django project:

### Step 1: Install Python
Ensure Python is installed on your machine. Check the version in your terminal:
```bash
python --version
```

### Step 2: Create a Virtual Environment (Recommended)
A virtual environment keeps your project's dependencies isolated from the rest of your system.
```bash
# 1. Create a virtual environment named 'myenv'
python -m venv myenv

# 2. Activate it
# On Windows (Command Prompt):
myenv\Scripts\activate
# On macOS/Linux:
source myenv/bin/activate
```

### Step 3: Install Django
Using Python's package manager (`pip`), install Django:
```bash
pip install django
```
Verify the installation:
```bash
django-admin --version
```

### Step 4: Create a New Project
Run the `django-admin` command to generate the boilerplate files for a new project named `myproject`:
```bash
django-admin startproject myproject
```

### Step 5: Start the Development Server
Navigate into the newly created folder and start the local server:
```bash
cd myproject
python manage.py runserver
```
*Open your browser and navigate to `http://127.0.0.1:8000/`. You should see the Django welcome rocket page!*
