# Django: Forms & Validation

Handling forms manually in backend web systems is repetitive: you must write HTML inputs, validate values on the server, check database constraints, format error feedback messages, and map values. Django's **Form Class** automates this.

---

## 1. What are Django Form Classes?

In Django, forms are represented by Python classes that inherit from `django.forms.Form` (or `django.forms.ModelForm` if binding directly to a model).

### Creating a Form Class (`forms.py`):
```python
from django import forms

class UserRegistrationForm(forms.Form):
    # Standard text input with required constraint
    username = forms.CharField(max_length=100, label="User Name")
    # Email input with built-in regex validator
    email = forms.EmailField(label="Email Address")
    # Textarea input widget
    feedback = forms.CharField(widget=forms.Textarea, required=False)
```

---

## 2. Rendering the Form in Templates

You don't need to write manual HTML `<input>` tags for each field. You pass the form object from the view to the template and render it:

```html
<!-- register.html -->
<form method="POST">
    <!-- CSRF token required by Django for security -->
    {% csrf_token %}
    
    <!-- Render all fields inside paragraph tags -->
    {{ form.as_p }}
    
    <button type="submit">Submit</button>
</form>
```
*Other rendering options include `{{ form.as_table }}` and `{{ form.as_ul }}`.*

## 3. Form Validation

When a user submits the form, Django provides built-in methods to inspect and sanitize data:

### A. Checking overall Validity: `is_valid()`
Calls all built-in validations. Returns `True` if all fields have valid data.
```python
if form.is_valid():
    # Retrieve clean sanitized data as a Python dictionary
    username = form.cleaned_data['username']
```

### B. Custom Validators: Clean Methods
You can write custom validation functions inside the Form class using the naming format `clean_<field_name>()`.

```python
from django import forms
from django.core.exceptions import ValidationError

class SignupForm(forms.Form):
    username = forms.CharField(max_length=50)
    age = forms.IntegerField()

    # Custom validator for age field
    def clean_age(self):
        age_value = self.cleaned_data.get('age')
        if age_value < 18:
            raise ValidationError("You must be at least 18 years old to sign up.")
        return age_value
```

## 4. How the View Coordinates Forms

A typical view checks whether it is receiving a **GET** request (to show a blank form) or a **POST** request (to process submitted data).

```python
# views.py
from django.shortcuts import render
from .forms import SignupForm

def signup_view(request):
    if request.method == "POST":
        # 1. Bind POST data to our Form Class
        form = SignupForm(request.POST)
        
        # 2. Check if valid
        if form.is_valid():
            # 3. Process data (save to DB, send emails, etc.)
            print(form.cleaned_data['username'])
            return render(request, 'success.html')
    else:
        # GET request: Instantiate a blank form
        form = SignupForm()

    # Pass the form object to the template context
    return render(request, 'signup.html', {'form': form})
```
